# Interface direction

Operate mode: a focused analyst workbench for daytime desktop use, with usable mobile reflow. Product facts are in PRODUCT.md.

The main surface has a narrow navigation rail, a question composer, a SQL/results workspace, and a metadata evidence panel. The signature interaction is switching between the query, result rows, and metadata used for the same run. Catalog, evaluations, and audit history are functional secondary views.

Use warm off-white surfaces, charcoal text, restrained forest-green actions, fine rules, and tabular numbers. Avoid decorative dashboards, unearned metrics, and chat bubbles that conceal SQL. Use a system body font for the application; monospace is reserved for SQL and identifiers. No external font or script dependency. This is a task interface, not a marketing landing page.

All controls require labels, keyboard focus, loading/empty/error states, and sufficient contrast. Honor reduced motion. Render untrusted content using text nodes, never HTML interpolation. Credentials stay in browser memory only.

The UI/UX skill search returned useful data-dashboard guidance; its sales-oriented page pattern did not fit this operate surface and was discarded after the prescribed narrower retry. The Impeccable launcher was unavailable; this file records a fallback design based on the agreed product workflow.
